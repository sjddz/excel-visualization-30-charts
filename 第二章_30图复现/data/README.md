# 数据说明

本目录是《Excel数据可视化——从图表到数据大屏》第二章的配套 Excel。

| 文件 | 对应图表 | 大小 |
|------|----------|------|
| `第二章 图表(前15).xlsx` | 图 01 ~ 15 | 194 KB |
| `第二章 图表(后15).xlsx` | 图 16 ~ 30 | 186 KB |

## 使用方式

- 无需任何操作，`common.py` 默认读取本目录。
- 每个工作表（sheet）对应一张图，sheet 名形如 `1 渐变柱形图`、`16 波浪水球图`。
- 脚本通过 sheet 名读取数据，**请勿重命名文件或 sheet**。

## 换数据

如果只想换数据、不改代码，设置环境变量指向新的数据目录即可：

```bash
# Windows (PowerShell)
$env:EXCEL_VIZ_DATA = "D:\my_data"

# macOS / Linux
export EXCEL_VIZ_DATA=/path/to/my_data
```

新目录下需保持同样的两个文件名。
