## 五、实现要点

1. **配色统一**：`common.py` 里集中定义商务蓝橙配色（`#4A90E2` / `#F5A623`）与渐变序列，30 张图风格一致。
2. **路径相对化**：`common.py` 用 `os.path.dirname(__file__)` 定位 `data/` 与 `charts/`，不再写死 Windows 盘符。
3. **Excel 专有图表手工绘制**：漏斗、甘特、水球、玫瑰、子弹图没有 matplotlib 原生类型，用 `patches` 的 `Wedge` / `FancyBboxPatch` / `Circle` 几何拼装。
4. **数据驱动**：所有数值都从 Excel 读取，不硬编码，换一套数据即可复用。
