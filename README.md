## 三、快速开始

```bash
git clone <仓库地址>
cd 商业数据分析

# 建议使用虚拟环境
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

运行（每个目录都可单独运行，路径已全部相对化，不需要改任何代码）：

```bash
# 1) 30 图复现
cd 第二章_30图复现
python charts_01_10.py && python charts_11_20.py && python charts_21_30.py
python make_summary.py          # 生成总览图与 HTML 汇总页

# 2) CDA 一级教材 7 章
cd ../CDA一级教材Python迁移
python 第1章_数据分析思维.py       # 其余章节同理
python make_summary.py

# 3) 6 个代表案例
cd ../其他教材Python迁移
python CDA二级_线性回归.py         # 其余脚本同理
```

各脚本会把图片写到本目录的 `charts/` 或 `images/`，控制台会打印每一步的关键指标。

## 五、迁移方法：从 Excel / Power BI / ipynb 到可运行脚本

### 5.1 Excel / Power BI → Python

| 教材中的操作 | Python 实现 | 说明 |
|--------------|-------------|------|
| 数据透视表（分组汇总） | `df.groupby().agg()` / `pivot_table` | 维度放 index、度量放 values，与透视表一一对应 |
| 切片器 / 筛选 | 布尔索引 `df[df.col == x]` | 交互式筛选变成参数化函数 |
| 计算字段、DAX 度量 | 新增列 / 聚合函数 | 如 `RFM` 的 R/F/M 打分用 `qcut` 分箱 |
| 图表（柱/折线/饼/散点） | `matplotlib` | 配色、标注、渐变均按原图还原 |
| 复杂图形（漏斗、甘特、子弹、玫瑰、水球） | `matplotlib.patches` 手工绘制 | Excel 原生图表没有对应类型，用几何图元拼 |
| Power BI 多图看板 | `plt.subplots()` 网格布局 | 一张画布复刻看板结构 |
| Excel 预测工作表 / 移动平均 | `statsmodels`（`seasonal_decompose`、`ARIMA`） | 效应分解、趋势外推 |
| SQL 查询 | `pandas`（`merge`/`groupby`/`isin`/`concat`） | 见 `第8章_SQL基础.py` 的逐条对照 |

### 5.2 ipynb → py 的处理原则

不是简单把单元格拼起来，而是按"能独立运行 + 能读懂"重写：

1. **去掉 Jupyter 专属语法**：`%matplotlib inline`、`get_ipython()`、隐式单元格输出；
2. **补上显式输出**：notebook 里靠"最后一个表达式自动回显"的结果，改成 `print()` / 保存图片 / 导出 CSV；
3. **修复原稿缺陷**：如 ARIMA 脚本引用了未定义变量、卡方检验写在循环外、依赖已停止维护的 `fa_kit` / `toad`，均给出可运行的等价实现；
4. **按流程分节**：读数据 → 清洗 → 建模 → 诊断 → 结论，每节有中文说明"为什么这么做"；
5. **路径相对化**：数据统一放 `data/`，换机器不用改代码。
