共 17 个脚本、115 张图片（30 张第二章图 + 61 张 CDA 图 + 23 张案例输出图 + 1 张总览图）。

## 运行

```bash
pip install -r requirements.txt

cd 第二章_30图复现 && python charts_01_10.py
cd CDA一级教材Python迁移 && python 第1章_数据分析思维.py
cd 其他教材Python迁移 && python CDA二级_线性回归.py
```

数据已放在各目录的 `data/` 下，脚本路径均为相对路径，clone 后无需修改代码。
每个子目录下另有 README，说明该目录的图表清单和数据来源。
